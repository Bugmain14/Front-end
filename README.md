# Gestión de Empleados - Frontend

Frontend de una aplicación full stack para gestionar empleados. Consume la API REST desarrollada en Spring Boot: [CRUD-Angular-Springboot](https://github.com/Bugmain14/CRUD-Angular-Springboot).

## Tecnologías

- Angular 15 y TypeScript
- Angular Material (tabla, paginación, diálogos y formularios)
- Formularios reactivos con validaciones

## Funcionalidades

- Listado de empleados con paginación
- Crear y editar empleados desde un diálogo
- Validaciones en los campos del formulario
- Eliminación de empleados
- Comunicación con la API mediante HttpClient

## Cómo ejecutarlo

Requisitos: Node.js, Angular CLI y la API corriendo en `http://localhost:8080`.

```bash
npm install
ng serve
```

Abre `http://localhost:4200`.
